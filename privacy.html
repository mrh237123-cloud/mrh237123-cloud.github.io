Privacy Policy

Applies to WildLogic Uploader. Last updated: 6 October 2026.

What the app is

WildLogic Uploader is a private tool run on the channel owner's own computer. It uploads videos made for the WildLogic YouTube channel, and their thumbnails, to that channel using the YouTube API Services. It has a single user: the channel owner.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • Google account authorization: an OAuth access token and refresh token for the youtube.upload permission, granted by the channel owner.
  • Upload results: the video ID and upload status YouTube returns for each uploaded video.

The app does not read, collect or store any other account data, viewer data, comments, contacts or analytics.

How data is used and stored

  • The token is used only to upload the channel's own videos and thumbnails.
  • The token and upload results are stored only on the channel owner's computer, in local files that are never published or committed to version control.
  • No data is sold, shared with or disclosed to any third party, and none is used for advertising.

Retention and deletion

The token is kept until access is revoked. Deleting the local token file removes it from the computer. You can revoke the app's access at any time from your Google Account's security settings: https://security.google.com/settings/security/permissions.

Cookies

This website and the app use no cookies, trackers or analytics.
